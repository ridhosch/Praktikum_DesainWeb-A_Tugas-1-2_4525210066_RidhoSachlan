# Profil R&D Universitas Pancasila

Proyek ini merupakan bentuk implementasi halaman web statis sederhana berbasis HTML yang menyajikan profil resmi Organisasi Research and Development (R&D) Universitas Pancasila.

## Deskripsi Singkat

Website ini berisi informasi mengenai organisasi R&D Universitas Pancasila yang berfokus pada bidang **Research and Development (R&D)** atau Penelitian dan Pengembangan.

Organisasi ini menjadi wadah bagi mahasiswa dari berbagai disiplin ilmu untuk mengembangkan keilmuan, melakukan riset, serta menciptakan solusi teknologi yang peka terhadap masalah sosial masyarakat.

## Struktur Halaman

Website terdiri dari beberapa bagian utama:

### 1. Tentang Organisasi
Berisi informasi mengenai organisasi R&D Universitas Pancasila dan misi organisasi.

### 2. Program dan Kegiatan
Program yang ditampilkan dalam website:

- **RND Scientific Class**
  - Pelatihan menyusun karya tulis ilmiah
  - Pelatihan jurnal
  - Persiapan Program Kreativitas Mahasiswa

- **Pancasila Research Competition**
  - Ajang lomba inovasi dan riset antar mahasiswa
  - Mendorong daya kritis civitas akademika Universitas Pancasila

### 3. Alur Pendaftaran

Tahapan pendaftaran anggota organisasi:

1. Mengisi formulir pendaftaran
2. Mengikuti sesi wawancara
3. Mengikuti diklat keorganisasian
4. Mengikuti penugasan proyek riset perdana anggota resmi

## Tag HTML yang Digunakan

| Tag | Fungsi |
|-----|--------|
| `<!DOCTYPE html>` | Menentukan bahwa dokumen menggunakan HTML5 |
| `<html lang="en">` | Elemen root dokumen HTML |
| `<head>`, `<meta>`, `<title>` | Berisi informasi dokumen, pengaturan karakter, viewport, dan judul halaman |
| `<body>` | Menampung seluruh konten yang ditampilkan pada halaman |
| `<h1>`, `<h2>`, `<h3>` | Membuat judul dan subjudul |
| `<p>` | Membuat paragraf |
| `<section>` | Mengelompokkan bagian konten tertentu berdasarkan ID |
| `<a>` | Membuat navigasi internal dan tautan eksternal seperti email, Instagram, website, dan YouTube |
| `<img>` | Menampilkan logo dan gambar kegiatan |
| `<ul>`, `<ol>`, `<li>` | Membuat daftar tidak berurutan dan daftar berurutan |
| `<dl>`, `<dt>`, `<dd>` | Membuat daftar definisi untuk nama program dan penjelasannya |
| `<hr>` | Membuat garis pemisah horizontal antarbagian |

## Cara Menjalankan

1. Simpan kode HTML sebagai `pertemuan2.html`.
2. Pastikan file gambar `rnd.png` berada di direktori yang sama dengan file HTML.
3. Buka file `pertemuan2.html` menggunakan browser seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge.
4. Jika menggunakan Visual Studio Code, file juga dapat dijalankan menggunakan ekstensi Live Server.
